# 阶段 1：视觉研究活页夹设计稿说明

## 设计判断

本检查器服务的是正在把一张参考图转成可执行设计判断的个人设计师；核心任务是快速回答：**这是什么、为什么有效、如何复用、如何管理**。因此它是 Operate 模式中的阅读密集型工具面，而不是一本拟真手帐。

本次以 `Barclay website in 1997` 的完整分析为设计载体。它本身具备手绘、扫描、拼贴与早期网页的质感，能检验纸张处理是否压过真实图片和文字。

## 选择的方向

**视觉研究活页夹**：右侧是插入工作台的硬纸板文件夹，内层是一张可持续滚动的暖白研究页；装订环与彩色索引负责定位，纸纹和铅笔批注只在标题、章节与关键结论处出现。

这不是泛用“暖白 + 衬线”纸张风：结构直接来自 Stylebase 的工作流程——四个彩色索引对应既有的四个可跳转章节，主纸页承接真实的长分析，夹子只固定最具证据价值的预览图。

### 令其不落入通用纸张风的修订

- 不使用豪华编辑部的衬线标题、咖啡渍或撕纸；正文继续使用项目的系统中文无衬线，保持工具感与中文阅读清晰度。
- 不把每个字段做成贴纸；只有章节索引、档案标签、预览夹与少量铅笔圈注表达材料感。
- 不让纸纹铺满文字区；纹理仅 3%–6% 可感知度，且不会降低正文对比度。

## 令牌与层级

| 层级 | 色彩 | 用途 |
| --- | --- | --- |
| 工作台 | `#E9E4D8` | 检查器外部留白；不与主内容竞争 |
| 硬纸板 | `#CBB998` | 纸页外露 8–12px 的底板 |
| 主纸页 | `#FFFDF6` | 可滚动分析内容 |
| 墨线 | `#191715` | 边界、正文、活页环轮廓 |
| 概览黄 | `#FFD51D` | 预览与摘要索引 |
| 视觉紫 | `#A98BFF` | 视觉 DNA、色票、为什么有效 |
| 实作蓝 | `#135DFF` | Recipe、Prompt 与复制操作 |
| 管理绿 | `#58A77B` | 来源、收藏、metadata、技术证据 |

正文延续 `Microsoft YaHei UI / Microsoft YaHei / DengXian / Noto Sans SC / Segoe UI / system-ui`。档案标签和索引用同一字体的 700 字重；铅笔批注为图形，不嵌入外部手写字体。

## 桌面端（≥ 1180px）

- 宽度：检查器 384px；硬纸板外露 10px；纸页净宽约 350px；右侧另留 28px 索引槽。
- 装订：8 个固定环置于纸页左侧，不随内容滚动；最小可点击内容保持在纸页内，不放在环上。
- 顶部：固定的档案标签头包含状态、最多两行标题与关闭；章节索引置于纸页右缘。
- 索引：概览／视觉分析／实作输出／资料管理依序为黄／紫／蓝／绿。当前项外移 5px，出现 2px 铅笔下划线；其余标签不抢正文注意力。
- 阅读：概览先给预览、状态、摘要和主要动作；视觉分析以更密的定义列表承接 DNA；Prompt 默认只露出摘要和复制，全文用 `details` 展开；metadata 与技术证据保持折叠。
- 滚动：只有主纸页滚动；硬纸板、环、索引槽、顶栏与当前索引保持定位。章节跳转沿用现有行为。

## 移动端（≤ 920px）

- 保留现有全屏层、返回／关闭语义和内容滚动。
- 取消右侧竖排耳朵，替换为顶部横向四个纸质分页标签；每个标签最小高度 44px，允许横向滚动。
- 暖白纸页充满视口；硬纸板仅以 8px 顶／侧边和柔和短投影提示，不减少可读宽度。
- 底部主操作仍固定，但改为一条薄纸带：复制 Prompt为蓝色主按钮，编辑 metadata 为墨线次按钮；不遮挡正文末行。

## 实现边界（供阶段 2 之后使用）

- 推荐路线维持原生 JS 模块化；本阶段未作代码变更。
- 首版由 CSS、项目自制静态 SVG 与小型纹理承载；无需框架迁移或持续运行的 Rough.js／GSAP。
- 交互动画仅限当前标签 120–180ms 的短位移和下划线；尊重 `prefers-reduced-motion`。
- 所有焦点、关闭、跳转、复制、收藏、metadata 与移动端返回保持现有 DOM 语义和事件。
