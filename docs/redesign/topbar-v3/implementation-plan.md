# Stylebase 顶部导航栏精改计划（V3）

## 1. 本轮范围

只精改顶部导航栏：品牌区、搜索框、汇入/扫描操作组、送交 Codex 主按钮及其响应式状态。

明确不改：

- 左侧导航栏。
- 中央素材瀑布流。
- 右侧分析检查器。
- 底部 Codex 队列。
- API、状态结构和业务行为。

## 2. 目标

恢复最初批准设计中的“手绘桌面窗口工具栏”效果，让顶部从普通后台工具条变成 Stylebase 的视觉入口，同时保持搜索、汇入、扫描和送交 Codex 功能完全不变。

参考基准：

- `docs/redesign/playful-handdrawn/final-design.png`
- `docs/redesign/playful-handdrawn/side-by-side-comparison.png`
- `docs/redesign/playful-handdrawn/desktop-current.png`

## 3. 当前问题

1. 品牌区域与左侧栏共用 `--rail-width: 184px`，吉祥物和字标被严重压缩。
2. STYLEBASE 字标依赖伪元素和负边距叠放，尺寸变化时容易错位。
3. 搜索框过度占据剩余空间，品牌、搜索和操作之间没有明确节奏。
4. 汇入、扫描和 Codex 三个按钮都是独立通用按钮，没有原稿中的分段工具组关系。
5. 顶栏缺少窗口灯、黑色手绘铭牌和轻微纸张/铅笔细节。
6. 中等宽度与移动端主要依靠隐藏文字，布局转换缺少明确层级。

## 4. 唯一设计方向

### 4.1 桌面结构

```text
● ● ●  [吉祥物][STYLEBASE 黑色铭牌]   [搜索任何视觉灵感……  /]   [汇入影像 | 扫描资料夹] [送交 Codex]
```

- 顶栏高度：82–88px。
- 品牌区：320–350px，不再与左侧导航栏等宽。
- 搜索框：420–520px × 44px，不无限拉伸。
- 次要操作组：汇入和扫描共用外边框，中间以铅笔竖线分隔。
- Codex 主按钮：独立钴蓝色按钮，与次要操作组间距 10–12px。
- 顶栏底部保留深色手绘基线，但厚度和粗糙度要克制。

### 4.2 品牌区

- 左侧三个装饰窗口灯：红、黄、绿，纯 CSS，`aria-hidden`。
- 使用现有吉祥物插画，不重新生成第一版素材。
- STYLEBASE 使用真实 HTML 文字，放入黑色轻微不规则铭牌。
- 吉祥物与铭牌有 8–12px 叠压关系，但文字不得与图片通过负边距硬拼。
- 桌面版保留完整品牌；窄屏逐步隐藏窗口灯并缩小吉祥物。

### 4.3 搜索框

- 暖白纸面、2px 石墨边框、轻微不对称圆角。
- 左侧搜索图标 19–20px。
- 占位文字使用“搜寻任何视觉灵感……”。
- 右侧保留 `/` 快捷键键帽。
- 聚焦：钴蓝边框、2–3px 蓝色纸张阴影、短手绘下划线。
- 不使用霓虹发光或大范围模糊阴影。

### 4.4 操作按钮

- 汇入与扫描组成分段纸质工具组。
- 每个操作保留独立 button、可访问名称和点击区域。
- Codex 主按钮使用星芒/灵感语义图标，不用普通勾选图标表达“送交”。
- Hover：上移 1px，并增加 2px 阴影。
- Active：回落，阴影收起。
- Disabled：使用蓝灰纸张色，文字和图标仍满足对比度。

### 4.5 视觉质感

第一版主要使用 CSS 与内联 SVG：

- CSS：布局、窗口灯、铭牌、按钮、阴影和状态。
- SVG：星芒图标、短铅笔线、轻微不规则轮廓。
- 现有 PNG：吉祥物。

只有在代码版本仍显得过于数字化时，才追加一张小型透明蜡笔颗粒覆盖层。不得把整个顶栏、字标、按钮文字或点击区域做成图片。

## 5. 响应式规格

### ≥ 1180px

- 完整窗口灯、吉祥物、STYLEBASE、搜索框和按钮文字。
- 品牌区 320–350px。

### 920–1179px

- 隐藏窗口灯。
- 品牌区缩至 230–260px。
- 搜索框保持最高空间优先级。
- 次要按钮适度减小水平内边距。

### 640–919px

- 顶栏改为两行。
- 第一行：品牌 + 三个操作图标按钮。
- 第二行：全宽搜索框。
- 按钮可隐藏文字，但保留 tooltip、title 或可访问名称。

### < 640px

- 吉祥物缩小，STYLEBASE 铭牌保留。
- 搜索框独占第二行。
- 操作按钮触控目标不小于 44×44px。
- 不允许按钮与品牌互相覆盖。

## 6. 分阶段执行

### 阶段 0：安全基线

- [ ] 读取本计划与三个参考图。
- [ ] 检查 `git status`，不得删除、覆盖或提交与顶部导航无关的未跟踪文件。
- [ ] 创建或切换到 `codex/topbar-v3` 分支。
- [ ] 运行 `npm run validate`。
- [ ] 捕获 1536、1180、920、640、390px 当前截图。

### 阶段 1：品牌区

- [ ] 顶栏网格与左侧栏宽度解耦。
- [ ] 重写品牌 DOM，移除伪元素负边距字标方案。
- [ ] 加入 CSS 窗口灯和黑色铭牌。
- [ ] 保持首页链接与可访问名称。
- [ ] 输出前后对比截图并检查各断点。

完成后暂停确认，不同时改搜索框和按钮。

### 阶段 2：搜索框

- [ ] 限制最大宽度和合理伸缩范围。
- [ ] 精修图标、占位文字、快捷键键帽。
- [ ] 加入 hover、focus-within 和键盘焦点状态。
- [ ] 验证搜索、清空和 `/` 快捷键行为。

完成后暂停确认。

### 阶段 3：操作区

- [ ] 把汇入/扫描改成分段工具组，但保持两个独立按钮。
- [ ] 精修 Codex 主按钮和禁用状态。
- [ ] 替换图标时只调整视觉，不改变按钮 ID 和事件绑定。
- [ ] 验证汇入、扫描、Codex 送交和禁用状态。

完成后暂停确认。

### 阶段 4：响应式与细节

- [ ] 实现四档响应式规格。
- [ ] 添加克制的纸张、铅笔线和按钮按压效果。
- [ ] 支持 `prefers-reduced-motion`。
- [ ] 检查中英文长度、系统字体和 200% 缩放。

### 阶段 5：最终验证

- [ ] 运行 `npm run validate`。
- [ ] 使用真实浏览器测试搜索、导入、扫描和送交。
- [ ] 捕获五个断点最终截图。
- [ ] 与最初设计稿并排比较。
- [ ] 对 HTML/CSS/JS 变更进行代码审查。

## 7. 验收标准

- 品牌不再被限制在 184px 内，吉祥物和字标无裁切、无错位。
- 第一眼能感受到最初设计中的手绘桌面窗口顶栏。
- 搜索仍是顶部最主要的工具，但不压迫品牌和操作区。
- 汇入/扫描形成清楚的工具组，Codex 是唯一主操作。
- 390–1536px 无重叠、横向溢出和不可点击区域。
- 键盘焦点清晰，按钮触控区足够，减少动态效果生效。
- 所有原有功能和测试保持通过。

## 8. 停止条件

出现以下情况必须暂停：

- 准备修改顶部以外的区域。
- 需要改变后端、API 或状态数据。
- 要整站迁移框架。
- 未展示阶段截图就准备继续下一阶段。
- 发现无法避免会覆盖用户现有未提交文件。
