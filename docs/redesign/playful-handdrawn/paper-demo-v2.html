Humanizing technology
柔和渐层 + 大量留白，传达信任与未来感。

标签：科技 · 极简 · 渐层 · 留白

Prompt：极简科技网站设计，柔和的紫蓝渐层球体，大量留白，干净排版，现代感。

v2 和 v1 的区别：

1. 纸底不再是纯色 + 噪点，而是 从你设计稿里裁出的真实纸纹理（paper-texture.jpg，90x90 平铺）——它就是参考图里的同一张纸
2. 高频噪点盖住平铺接缝，重复感不可见
3. 活页孔是"仿真孔"：外圈纸厚度切面 + 内圈透出下层阴影 + 底部暗弧（光从上方来）
4. 卷边带渐变（边缘亮、内侧暗）+ 卷角下的投影
5. 多层 box-shadow 模拟纸的受光和厚度

原理一句话：拟真素材要用拟真素材还原。矢量形状负责结构，真实纹理负责质感。
