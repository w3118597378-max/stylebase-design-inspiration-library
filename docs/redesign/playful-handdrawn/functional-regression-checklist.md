# 功能与验收清单

## 自动检查

- [ ] `npm run check`
- [ ] `npm test`
- [ ] `npm run smoke`
- [ ] `npm run validate:release`
- [ ] 或直接执行 `npm run validate`

## 核心功能

- [ ] 页面能正常读取本地资料库。
- [ ] 导入单张和多张图片正常。
- [ ] 扫描资料夹正常。
- [ ] 搜索、领域筛选、状态筛选和排序正常。
- [ ] 点击素材打开检查器。
- [ ] 方向键切换素材，Esc 关闭检查器。
- [ ] 单选与批量选中状态不会混淆。
- [ ] 单张和批量“送交 Codex”正常。
- [ ] 队列展开、进度更新、错误详情和重试正常。
- [ ] 收藏集创建、加入、移除和条件式收藏正常。
- [ ] 标题、来源 URL 和权利备注保存正常。
- [ ] 设置弹窗与 Codex 就绪状态正常。
- [ ] 空、加载、错误、未就绪、缺失和需更新状态均能显示。

## 无障碍

- [ ] Tab 顺序与改造前一致且合理。
- [ ] 所有按钮有可见焦点。
- [ ] 插画不重复朗读导航文字。
- [ ] 状态不只依赖颜色。
- [ ] 正文和控件达到 WCAG AA 对比度。
- [ ] 200% 缩放时无关键内容丢失。
- [ ] `prefers-reduced-motion` 下停止非必要动画。

## 响应式

- [ ] 1440px 桌面接近 `final-design.png` 的构图。
- [ ] 1180px 下中央素材仍可浏览。
- [ ] 920px 下导航转为横向，检查器成为全屏层。
- [ ] 640px 下素材双列，操作按钮不溢出。
- [ ] 队列在窄屏下仍可读、可展开、可重试。

## 视觉完成度

- [ ] 左栏采用工具筒与黄色素材库贴纸。
- [ ] 素材图片无滤镜、无装饰遮挡。
- [ ] 选中素材为蓝色蜡笔双圈。
- [ ] 右栏具有活页笔记本语言但字段完整。
- [ ] 队列角色与文字、进度条同时存在。
- [ ] 手绘元素属于同一插画系统，不混用 emoji 或不同画风图标。
- [ ] 页面没有退化为通用圆角 SaaS 卡片。
