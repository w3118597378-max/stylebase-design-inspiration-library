# 实施方案

## 1. 基础视觉系统

- 在 `public/styles.css` 重建视觉变量：纸张、墨黑、群青蓝、向日葵黄、珊瑚红、叶绿色、淡紫色。
- 保留现有中文系统字体栈，加入仅供字标使用的 SVG 资产。
- 建立统一墨线粗细、蜡笔圈选、纸张表面、阴影和焦点样式。
- 保持控件近方形，允许边框轻微不规则，但点击区域和布局必须规整。

## 2. 顶部工具栏

- 将文字 Logo 替换为 `stylebase-logo.svg`，保留原链接与无障碍名称。
- 搜索框改成手绘墨线输入框，快捷键提示继续保留。
- 普通按钮使用白纸和墨线，主按钮使用群青蓝色块。
- 禁用、悬停、焦点和等待状态必须完整覆盖。

## 3. 左侧导航

- 采用最终稿中的 B 方案导航：工具筒、黄色素材库贴纸、文件托盘、爱心手账、队列机器人、工具齿轮。
- 保留所有原始按钮、`data-view`、`data-action`、计数和 `aria-current`。
- 插画标记为装饰性内容，文字仍是主要可访问标签。
- 底部加入“灵感，有迹可循。”便签。

## 4. 素材网格

- 保留 `renderGallery()`、`renderAssetCard()` 的数据与交互逻辑。
- 通过 `asset-card`、`asset-open`、`asset-state` 等现有类完成视觉替换。
- 当前检查对象使用蓝色蜡笔双圈；批量选中使用不同的角标/勾选，二者不可混淆。
- 不给素材图片添加滤镜、颜色蒙版或装饰裁切。
- 保留当前异形网格与移动端两列规则。

## 5. 右侧检查器

- 将 `inspector` 视觉改造成活页笔记本，但保持现有章节顺序和字段。
- 活页孔、纸夹、标签页和涂鸦作为装饰层，不进入阅读顺序。
- 色票显示为颜料笔触形状，但继续显示可读色值。
- Prompt Kit、来源证据、收藏和 metadata 编辑全部保留。
- 920px 以下继续使用全屏检查器行为。

## 6. Codex 队列

- 将 `queue-job` 改造成横向灵感处理流水线。
- 等待、分析、完成、错误分别配套角色插画。
- 保留缩略图、阶段文字、百分比、进度条、错误详情和重试操作。
- 角色不能遮挡进度信息；动画在减少动态偏好下停用。

## 7. 弹窗与系统状态

- 收藏集、设置弹窗改成手绘纸张面板。
- Toast 改为便签式反馈。
- 空素材库、加载、读取错误、Codex 未就绪和合成示意状态全部覆盖。
- 错误状态使用红色、图形和文字三重表达。

## 8. 响应式

- `>1180px`：完整桌面构图。
- `921–1180px`：缩窄左栏与检查器，保证中央素材宽度。
- `641–920px`：左侧导航转换为横向图标导航，检查器全屏。
- `<=640px`：素材双列、简化按钮文案、队列紧凑显示。

## 9. 推荐实施批次

1. 视觉变量、纸张背景和基础控件。
2. Logo、左侧导航插画和导航布局。
3. 素材卡片、筛选器、选中和批量状态。
4. 右侧活页检查器。
5. 底部队列与状态角色。
6. 弹窗、Toast、空/加载/错误状态。
7. 响应式、无障碍和减少动态支持。
8. 测试、桌面/移动截图、机械设计检查与最终评审。

每个批次完成后先验证功能，再进入下一批；不要在第一步重写整个 DOM。
